## What this site is for

This site helps people compare median home sale prices across 18 college towns using completed sales from the College-town home sales dataset

## Live site

https://riyakark.github.io/campustown-home-sales-site/  

## Data notes

This site excluded sales below $10,000 because the dataset includes implausible prices; medians use all remaining sales for each city and state, with repeated addresses counted as separate sales. The page uses sale price only and does not rely on home type, assessed value, days on market, or other fields flagged in the data notes.
